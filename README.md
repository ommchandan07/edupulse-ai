# EduPulse AI — AI version

This is the version matching your idea:
- Generate notes for any topic/subject using Gemini AI.
- Upload PDF/PPTX/TXT/MD/CSV and get short study notes.
- Paste a public YouTube link and get a short explanation.
- English and Hindi output.
- Flashcards and quiz can be added to the same dashboard.

## Run
1. Install Node.js.
2. Open this folder in VS Code.
3. Open Terminal.
4. Run `npm install`
5. Copy `.env.example` to `.env`.
6. Put your Gemini API key in `.env`.
7. Run `npm start`.
8. Open `http://localhost:3000`.

Do NOT put the API key in frontend JavaScript. Do NOT use Live Server for this AI version; the Node server handles the API key.
